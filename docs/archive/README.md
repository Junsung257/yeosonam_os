# Archive manifest

`docs/archive`는 대체되거나 완료된 문서의 역사 보관소다. 현재 정책이나 실행 지침이 아니며 현재 규칙 검색에서는 제외한다.

- 현재 권위: `CURRENT_STATUS.md`, `docs/document-registry.yml`, 도메인 current SSOT
- 일회성 검증 증거: `docs/audits`
- 대체·완료·과거 상태: `docs/archive`
- 이번 이동·복구 매핑: [2026-09-01 refactor manifest](harness/2026-09-01-refactor-manifest.md)

archive 내용을 현재 정책으로 되살릴 때는 현행 코드·테스트·SSOT와 다시 검증한다.
